# Win7Taskbar

This repository contains a Windows 7-inspired taskbar replacement for Windows 10 and Windows 11, implemented with C#/WPF and native C++ components.

> **Status: Alpha**
>
> This project is currently in an early alpha stage and is still incomplete. Features and functionality are actively being developed.

## Requirements

- Windows 10 or Windows 11
- .NET Runtime

## Tested On
This software has been currently tested on:
- Windows 10 21H2

## Inspiration

This project is mainly inspired by:

- RetroBar
- Open-Shell
- ExplorerPatcher
